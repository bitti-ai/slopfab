# H3 W6A8 ConvRot transformer

Slopfab loads `Minimax-h3_Singularity_x_10Eros-Max_PRISM_w6a8.safetensors`
directly on CUDA and Vulkan. Select the file as the transformer in the CLI or
with `slopfab_request_set_model_path`; no conversion or quantization flag is
needed. Model inspection reports `W6A8 INT6 ConvRot`. This checkpoint remains
an H3 Ref2VA model; W6A8 does not impose a distilled sampling schedule.
The release filename identifies this otherwise metadata-poor file as Ref2VA,
as documented by its [publisher](https://huggingface.co/OliviaRossi/Minimax-h3_Singularity-x-10Eros-Max_PRISM).
If you rename it, retain `ref2va` in the filename or supply explicit
`slopfab.model` capability metadata.

## Storage and execution

The `w6a8_int8` descriptor identifies packed INT8 storage shaped `[N,3*K/4]`.
Each row contains `K/2` bytes of low nibbles (even columns first), followed by
`K/4` bytes of high two-bit fields (shifts 0, 2, 4, 6). Reconstructed codes
use uniform levels `code - 32`, without a codebook. The format follows the
[Comfy Kitchen codec](https://github.com/Comfy-Org/comfy-kitchen/blob/main/comfy_kitchen/tensor/w4a8_packed.py)
and [reference arithmetic](https://github.com/Comfy-Org/comfy-kitchen/blob/main/comfy_kitchen/backends/eager/w4a8_int8.py).

An E4M3 scale per weight group reconstructs signed INT8 weights using
nearest-even rounding and clipping to [-127,127]. This checkpoint uses groups
of 32; groups divisible by 16 that divide K are supported. Activations use
ConvRot-256, BF16 rounding, and dynamic per-row INT8 quantization. Matrix
multiplication accumulates in INT32, then applies the original FP32 activation
and output-channel scales before BF16 output.

Weights remain packed in model storage. CUDA expands one projection into INT8
scratch for GEMM; Vulkan decodes tiles during integer multiplication. Q/K/V
views slice both packed rows and group/channel scales. CUDA block offloading
preserves those views. FP32/BF16/F16 endpoint weights, biases, and norms are
converted to the runtime's compute types when loaded.

Descriptors may be per-layer `.comfy_quant` tensors or checkpoint-wide
`_quantization_metadata`, including nested `params`. Unsupported layouts fail
explicitly: non-256 rotation, non-E4M3 group scales, W6 codebooks, asymmetric
correction tensors, AWQ pre-scales, interleaved packed QKV, and
`full_precision_matrix_mult=true`. This support applies to H3 transformer
weights; it does not add W6A8 VAE or text-encoder support.

## Verification

Host tests validate descriptors, packed shapes, scale values, and invalid
auxiliaries. CUDA and Vulkan tests exercise all six-bit codes, group sizes
16/32/64, zero inputs, rounding, saturation, and output-channel scaling.
The existing W4A8 tests remain enabled.

The independent PyTorch comparison uses the actual checkpoint's QKV,
attention-output, and both MLP projections. All four match exactly on both
CUDA and Vulkan on the tested RTX 5090:

```sh
python tools/w4a8_reference.py --probe build/Release/slopfab_w4a8probe.exe --model weights/transformer/Minimax-h3_Singularity_x_10Eros-Max_PRISM_w6a8.safetensors
python tools/w4a8_reference.py --probe build/Release/slopfab_vulkan_w4a8probe.exe --model weights/transformer/Minimax-h3_Singularity_x_10Eros-Max_PRISM_w6a8.safetensors
```

These development checks require PyTorch and safetensors; inference does not.
The shared probe names retain `w4a8` and detect either format from metadata.

The full checkpoint passes the DLL masked-image smoke test on both backends,
including finite decoded output, buffer ownership, and exact preservation of
all 6,042 unselected color channels. CUDA also passes with
`SLOPFAB_DIT_OFFLOAD_BLOCKS=45`. Vulkan used 14.81 GiB persistent transformer
storage and 15.39 GiB peak for this 11-row test.

Mixed image/video/audio RefMods also pass full generation on both backends:
22 video frames at 32x32 and 29,600 stereo audio samples, with finite output
and source files deleted before generation. Run the same check with:

```sh
python tools/refmod_generation_smoke.py build/Release/slopfab.dll . cuda embedding transformer=weights/transformer/Minimax-h3_Singularity_x_10Eros-Max_PRISM_w6a8.safetensors
python tools/refmod_generation_smoke.py build/Release/slopfab.dll . vulkan embedding transformer=weights/transformer/Minimax-h3_Singularity_x_10Eros-Max_PRISM_w6a8.safetensors
```

These checks establish numeric
and execution correctness; they do not measure image quality or full-pipeline
parity with ComfyUI.
