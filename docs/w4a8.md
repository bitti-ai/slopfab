# H3 W4A8 ConvRot transformer

C API 1.36 supports the supplied `minimax_h3_fl2va_pruned-w4a8_convrot_pruned.safetensors` directly on CUDA and Vulkan. No conversion or quantization flag is needed. Architecture detection remains H3 FL2VA with a pruned AdaLN table; the quantization report identifies W4A8 INT4 ConvRot.

The file stores two 4-bit weight codes per INT8 byte, low nibble first. A 16-entry asymmetric codebook and E4M3 scale per 16 weights reconstruct the rotated INT8 weight matrix. Inference applies ConvRot-256 to BF16 activations, quantizes each activation row dynamically to INT8, accumulates INT8 products in INT32, and applies the activation/channel scales before BF16 output. This differs from ordinary INT8 ConvRot and from NVFP4/NF4.

Descriptors can be supplied in per-layer `.comfy_quant` tensors or the checkpoint's `_quantization_metadata` header. Packed shapes, auxiliary shapes, scale values and codebooks are validated. Q/K/V slicing includes both group and channel scales; block offloading relocates the codebook too. Weights remain packed in model storage, with temporary INT8 expansion during execution.

## DLL

Use `dist/windows/slopfab.dll` with its matching `capi.h`. Set the transformer model path to your file and select `SLOPFAB_INFERENCE_CUDA` or `SLOPFAB_INFERENCE_VULKAN`. Existing H3 text encoder, video/audio VAE, prompt, resolution and sampling controls continue to apply. The model retains the ordinary H3 schedule; it is not an eight-step distilled model.

Vulkan keeps weights packed and decodes tiles during INT32 matrix multiplication. It uses portable integer shaders without requiring integer dot-product or cooperative-matrix extensions. The per-row quantizer retains explicit BF16 rounding and nearest-even integer rounding. Dispatches span multiple workgroup rows when needed. This addition does not enable unrelated INT4 formats, including the separate Qwen INT4 checkpoint used with Fibo. Interleaved W4A8 QKV layouts and extra asymmetric correction tensors remain unsupported.

## Verification

Host tests cover checkpoint-wide metadata, missing layers, shape errors and invalid scales. CUDA tests cover packed decoding, ConvRot, BF16 activation quantization, integer accumulation, output scaling, zero rows and both native-mode settings.

Vulkan tests compare an independent CPU Hadamard/integer reference, including zero rows, saturation, ties, partial tiles, invalid auxiliaries, aliased buffers and a dispatch exceeding 65,535 workgroups.

```sh
python tools/w4a8_reference.py --probe build/Release/slopfab_w4a8probe.exe --model weights/transformer/minimax_h3_fl2va_pruned-w4a8_convrot_pruned.safetensors
python tools/w4a8_reference.py --probe build/Release/slopfab_vulkan_w4a8probe.exe --model weights/transformer/minimax_h3_fl2va_pruned-w4a8_convrot_pruned.safetensors
```

This development-only tool requires PyTorch and safetensors; production inference requires neither. It compares actual QKV, attention-output and both MLP projections with independent INT8 PyTorch calculations. All four pass with relative RMS error below 0.001% on CUDA and match exactly on the tested Vulkan device (RTX 5090, driver 610.88).

The supplied full checkpoint also passes CUDA masked image generation through the DLL with 45 of 50 transformer blocks offloaded to CPU. The smoke test produces finite output and preserves all 6,042 channels outside the mask exactly, including after caller buffers and the request are released.

The same masked-generation test passes on Vulkan, including VAE encoding/decoding and exact preservation of all 6,042 channels outside the mask. For this 67x65 test, the Vulkan transformer used 13.20 GiB persistent storage and 13.78 GiB peak storage.

Shader artifacts are pinned in `cmake/ShaderManifest.cmake`. Regenerate them with `python tools/build_vulkan_w4a8.py --glslang PATH_TO_GLSLANG_16_5_0`. The quantizer omits explicit FP32 RTE execution controls to avoid an NVIDIA 610.88 shader-compiler crash involving division; its BF16/integer rounding is implemented in the shader. A 1e-30 scale floor makes subnormal activations quantize to zero.
